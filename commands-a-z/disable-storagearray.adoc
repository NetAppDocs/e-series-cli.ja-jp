= ストレージアレイ機能を無効にする - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
disable storageArrayコマンドは'ストレージ・アレイ機能を無効にします



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべての SMcli パッケージがインストールされている限り、E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50、および EF80 アレイを含む、あらゆる個々のストレージアレイに適用されます。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage Adminロールが必要です。



[[context]]
== コンテキスト（Context）

show storageArrayコマンドを実行して、ストレージアレイ内で有効になっているすべての機能の識別子のリストを表示します。



[[syntax]]
== 構文

[source, cli, subs="+macros"]
----
pass:quotes[disable storageArray (featurePack | feature=_featureAttributeList_)]
----
pass: quotes [`_featureAttributeList_`]には'これらの属性値の1つ以上を指定できます複数の属性値を入力する場合は、値をスペースで区切ります。

* 「ドライブセキュリティ」




[[parameters]]
== パラメータ

なし



[[minimum-firmware-level]]
== 最小ファームウェアレベル

8.20で'driveSecurity'属性が追加され'その他の属性がすべて削除されました
