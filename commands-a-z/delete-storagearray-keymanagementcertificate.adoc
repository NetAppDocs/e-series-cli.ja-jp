= インストールされた外部キー管理証明書を削除する - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
delete storageArray keyManagementCertificateコマンドは、インストールされている外部キー管理証明書をストレージアレイから削除します。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、個々のE4000、E2800、E5700、EF600、EF300、EF50、およびEF80ストレージアレイに適用されます。E2700またはE5600ストレージアレイでは動作しません。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Security Adminロールが必要です。



[[context]]
== コンテキスト（Context）

[NOTE]
====
このコマンドは、外部キー管理にのみ適用されます。

====


[[syntax]]
== 構文

[source, cli, subs="+macros"]
----
pass:quotes[delete storageArray keyManagementCertificate certificateType=_certificate_type_]
----


[[parameters]]
== パラメータ

[cols="2*"]
|===
| パラメータ | 説明 


 a| 
「certificateType」
 a| 
削除する証明書のタイプを指定できます。有効な選択肢は「client」または「server」です。

|===


[[example]]
== 例

[listing]
----
 SMcli -n Array1 -c "delete storageArray keyManagementCertificate certificateType="client";"

   SMcli completed successfully.
----


[[minimum-firmware-level]]
== 最小ファームウェアレベル

8.40
