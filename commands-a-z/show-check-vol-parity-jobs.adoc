= ボリュームパリティチェックジョブの表示 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
。 `show check volume parity jobs` コマンドは、すべてのボリュームチェックパリティジョブとそのステータスを表示します。



== サポートされているアレイ

このコマンドは、EF600、EF300、EF50、EF80アレイを含む、あらゆる個々のストレージアレイに適用されます（ただし、すべてのSMcliパッケージがインストールされている必要があります）。



== ロール

EF600、EF300、EF50、およびEF80ストレージアレイでこのコマンドを実行するには、Storage Adminロールが必要です。



== 構文

[source, cli, subs="+macros"]
----
show check volume parity jobs;
----


== パラメータ

なし



== 最小ファームウェアレベル

11.80
