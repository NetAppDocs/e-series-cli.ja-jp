= ホストポートの表示 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「show allHostPorts」コマンドは、設定されたホストポートに関する情報を返します。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべての SMcli パッケージがインストールされている限り、E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50、および EF80 アレイを含む、あらゆる個々のストレージアレイに適用されます。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage Adminロールが必要です。



[[context]]
== コンテキスト（Context）

このコマンドは、ストレージアレイに接続されているすべてのホストポートについて次の情報を返します。

* ホストポートの識別子
* ホストポート名
* ホストタイプ




[[syntax]]
== 構文

[source, cli]
----
show allHostPorts
----


[[parameters]]
== パラメータ

なし



[[notes]]
== 注：

このコマンドから返されるHBAホストポート情報の例を次に示します。

[listing]
----
HOST PORT IDENTIFIER     HOST PORT NAME  HOST TYPE
12:34:56:54:33:22:22:22  Jupiter1        Solaris
12:34:56:78:98:98:88:88  Pluto1          Windows 2000/Server 2003 Clustered
54:32:12:34:34:55:65:66  Undefined       Undefined
----


[[minimum-firmware-level]]
== 最小ファームウェアレベル

5.40
