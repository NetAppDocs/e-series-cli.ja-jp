= ホストグループの削除 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
delete hostGroupコマンドは'ホスト・グループを削除します



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべての SMcli パッケージがインストールされている限り、E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50、および EF80 アレイを含む、あらゆる個々のストレージアレイに適用されます。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage Adminロールが必要です。



[[context]]
== コンテキスト（Context）

[NOTE]
====
*ストレージアレイ構成への損傷の可能性*-このコマンドは、ホストグループ内のすべてのホスト定義を削除します。

====


[[syntax]]
== 構文

[source, cli, subs="+macros"]
----
pass:quotes[delete hostGroup [_hostGroupName_]]
----


[[parameter]]
== パラメータ

[cols="2*"]
|===
| パラメータ | 説明 


 a| 
「hostGroup」と入力します
 a| 
削除するホストグループの名前。ホストグループ名は角かっこ（[]）で囲みます。ホストグループ名が特殊文字を含んでいる場合または数字のみで構成される場合は、ホストグループ名を二重引用符（""）で囲んだ上で角かっこで囲む必要があります。

|===


[[notes]]
== 注：

ホストグループはオプションのトポロジ要素であり、同じボリュームへのアクセスを共有する一連のホストです。ホストグループは論理エンティティです。



[[minimum-firmware-level]]
== 最小ファームウェアレベル

5.20
