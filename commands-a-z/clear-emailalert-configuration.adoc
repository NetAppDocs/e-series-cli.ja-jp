= 電子メールアラート設定のクリア - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
clear emailAlert configurationコマンドは'電子メールアラート設定をデフォルト値にクリアします



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、個々のE4000、E2800、E5700、EF600、EF300、EF50、およびEF80ストレージアレイに適用されます。E2700またはE5600ストレージアレイでは動作しません。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage AdminまたはSupport Adminロールが必要です。



[[syntax]]
== 構文

[source, cli]
----
clear emailAlert configuration
----


[[parameters]]
== パラメータ

なし



[[examples]]
== 例

[listing]
----

SMcli -n Array1 -c "clear emailAlert configuration;"

SMcli completed successfully.
----


[[minimum-firmware-level]]
== 最小ファームウェアレベル

8.40
