= ストレージアレイホストI/Oプロトコル情報の表示 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
 `show storageArray hostIoProtocolInformation`コマンドは、特定のストレージアレイのI/Oプロトコル設定に関する情報を表示します。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべてのSMcliパッケージがインストールされている限り、E4000、EF50、またはEF80ストレージアレイに適用されます。



[[roles]]
== ロール

E4000、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、サポート管理者ロールが必要です。



[[syntax]]
== 構文

[source, cli, subs="+macros"]
----
show storageArray hostIoProtocolInfo;
----


[[parameter]]
== パラメータ

なし



[[minimum-firmware-level]]
== 最小ファームウェアレベル

12.00
