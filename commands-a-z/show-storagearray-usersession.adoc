= ストレージアレイのユーザーセッションを表示する - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「show storageArray userSession」コマンドを使用すると、System Managerのセッションタイムアウト時間を表示できます。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、個々のE4000、E2800、E5700、EF600、EF300、EF50、およびEF80ストレージアレイに適用されます。E2700またはE5600ストレージアレイでは動作しません。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage AdminまたはSupport AdminまたはStorage Monitorロールが必要です。



[[parameters]]
== パラメータ

なし



[[syntax]]
== 構文

[source, cli]
----
show storageArray userSession
----


[[minimum-firmware-level]]
== 最小ファームウェアレベル

8.41
