= 非同期ミラーリングを無効化 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「これには、ストレージの非アクティブ化機能」を使用します。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべてのSMcliパッケージがインストールされていれば、E2700、E5600、E2800、E5700、EF600、EF300を含むあらゆるストレージ アレイに適用されます。



[[roles]]
== ロール

このコマンドをE2800、E5700、EF600、またはEF300のストレージ アレイに対して実行するには、Storage Adminロールが必要です。



[[context]]
== コンテキスト（Context）

非同期ミラーリング機能を非アクティブ化する前に、既存のすべての非同期ミラーグループまたは非同期ミラーペアを、ローカルストレージアレイとリモートストレージアレイから削除する必要があります。



[[syntax]]
== 構文

[source, cli]
----
deactivate storageArray feature=asyncRemoteMirror
----


[[parameters]]
== パラメータ

なし



[[minimum-firmware-level]]
== 最小ファームウェアレベル

7.84
