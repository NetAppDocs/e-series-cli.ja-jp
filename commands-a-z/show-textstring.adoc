= 文字列を表示 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「show textstring」コマンドは、スクリプトファイルのテキスト文字列を表示します。このコマンドは、MS-DOSおよびUNIXの「echo」コマンドと似ています。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべての SMcli パッケージがインストールされている限り、E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50、および EF80 アレイを含む、あらゆる個々のストレージアレイに適用されます。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage AdminまたはStorage Monitorロールが必要です。



[[syntax]]
== 構文

[source, cli, subs="+macros"]
----
pass:quotes[show "_textString_"]
----


[[parameters]]
== パラメータ

なし



[[notes]]
== 注：

文字列は二重引用符（""）で囲みます。



[[minimum-firmware-level]]
== 最小ファームウェアレベル

6.10
