= Syslog 設定をクリアする - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
clear syslog configurationコマンドは、syslogアラート情報をクリアします。



== サポートされているアレイ

このコマンドは、個々のE4000、E2800、E5700、EF600、EF300、EF50、およびEF80ストレージアレイに適用されます。E2700またはE5600ストレージアレイでは動作しません。



== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage AdminまたはSupport Adminロールが必要です。



== 構文

[source, cli]
----
clear syslog configuration
----


== パラメータ

なし



== 例

[listing]
----

SMcli -n Array1 -c "clear syslog configuration;"

SMcli completed successfully.
----
