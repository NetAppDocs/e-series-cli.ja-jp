= ストレージアレイを設定してキャッシュミラーデータアシュアランスチェックを有効または無効にする - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
set storageArray cacheMirrorDataAssuranceCheckEnableコマンドを使用すると、キャッシュミラーのData Assuranceチェックを有効または無効にできます。



== サポートされているアレイ

このコマンドは、個々のE4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイに適用されます。E2700またはE5600ストレージアレイでは動作しません。



== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage AdminまたはSupport Adminロールが必要です。



== 構文

[source, cli]
----
set storageArray cacheMirrorDataAssuranceCheckEnable=(TRUE | FALSE)
----


== パラメータ

なし
