= 証明書の表示 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[Show certificates]コマンドを使用すると、CLIパッケージの信頼ストアにインストールされている証明書を表示できます。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、EF600、EF300、EF50、およびEF80ストレージ アレイに適用されます。



[[syntax]]
== 構文

[source, cli]
----
show localCertificate all | alias alias
----


[[parameters]]
== パラメータ

[cols="2*"]
|===
| パラメータ | 説明 


 a| 
「alias」
 a| 
ユーザ定義のエイリアスを使用して証明書を指定できます。

|===


[[minimum-firmware-level]]
== 最小ファームウェアレベル

8.60
