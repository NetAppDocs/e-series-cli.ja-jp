= メールアラートの受信者を削除する - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「delete emailAlert」コマンドは、電子メールアラート設定から受信者の電子メールアドレスを削除します。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、個々のE4000、E2800、E5700、EF600、EF300、EF50、およびEF80ストレージアレイに適用されます。E2700またはE5600ストレージアレイでは動作しません。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage AdminまたはSupport Adminロールが必要です。



[[syntax]]
== 構文

[source, cli, subs="+macros"]
----
delete emailAlert
       (allEmailRecipients |
        emailRecipients pass:quotes[[_emailAddress1 ... emailAddressN_]])
----


[[parameters]]
== パラメータ

|===
| パラメータ | 説明 


 a| 
「allEmailRecipients」を参照してください
 a| 
すべてのEメール受信者を削除できます。



 a| 
「Eメール受信者」
 a| 
受信者アドレスを削除できます。Eメールアドレスは角かっこ（[]）で囲みます。

|===


[[examples]]
== 例

[listing]
----

SMcli -n Array1 -c "delete emailAlert allEmailRecipients;"

SMcli -n Array1 -c "delete emailAlert emailRecipients ["person1@email.domain.com" "person3@email.domain.com"];"

SMcli completed successfully.
----

== 最小ファームウェアレベル
