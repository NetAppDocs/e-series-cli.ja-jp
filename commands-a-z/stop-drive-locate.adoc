= ドライブの検索を停止する - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
stop drive locateコマンドは'start drive locateコマンドによってオンにされたドライブのインジケータライトを消灯します



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべての SMcli パッケージがインストールされている限り、E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50、および EF80 アレイを含む、あらゆる個々のストレージアレイに適用されます。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage Adminロールが必要です。



[[syntax]]
== 構文

[source, cli]
----
stop drive locate
----


[[parameters]]
== パラメータ

なし



[[minimum-firmware-level]]
== 最小ファームウェアレベル

6.10
