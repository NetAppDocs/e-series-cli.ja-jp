= ストレージアレイファームウェアの保留領域をクリアする - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
clear storageArray firmwarePendingArea'コマンドは'以前にダウンロードしたファームウェアイメージまたはNVSRAM値を保留領域バッファから削除します



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、すべての SMcli パッケージがインストールされている限り、E4000、E2700、E5600、E2800、E5700、EF600、EF300、EF50、および EF80 アレイを含む、あらゆる個々のストレージアレイに適用されます。



[[roles]]
== ロール

E4000、E2800、E5700、EF600、EF300、EF50、またはEF80ストレージアレイでこのコマンドを実行するには、Storage Adminロールが必要です。



[[context]]
== コンテキスト（Context）

[NOTE]
====
*ストレージアレイ構成への損傷の可能性*--このコマンドを実行すると'ストレージアレイの既存の保留領域の内容がただちに削除されます

====


[[syntax]]
== 構文

[source, cli]
----
clear storageArray firmwarePendingArea
----


[[parameters]]
== パラメータ

なし
