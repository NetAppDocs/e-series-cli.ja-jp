= ボリュームパリティチェックジョブの表示 - SANtricity CLI
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
。 `show check volume parity job` コマンドは、指定したボリュームチェックパリティジョブとジョブのステータスを表示します。



[[supported-arrays]]
== サポートされているアレイ

このコマンドは、EF600、EF300、EF50、EF80アレイを含む、あらゆる個々のストレージアレイに適用されます（ただし、すべてのSMcliパッケージがインストールされている必要があります）。



[[roles]]
== ロール

EF600、EF300、EF50、およびEF80ストレージアレイでこのコマンドを実行するには、Storage Adminロールが必要です。



[[syntax]]
== 構文

[source, cli, subs="+macros"]
----
show check volume parity job jobId=<job_id>;
----


[[parameters]]
== パラメータ

|===
| パラメータ | 説明 


 a| 
`jobId`
 a| 
ボリュームチェックパリティジョブID。この値は必須です。

|===


[[minimum-firmware-level]]
== 最小ファームウェアレベル

11.80
